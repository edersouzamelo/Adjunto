# Adjunto

Repositório privado de desenvolvimento de uma extensão de navegador para automação assistida de rotinas administrativas.

## Estado

- Versão local de referência a importar e revisar: **1.1.29**.
- O código-fonte completo ainda **não foi sincronizado** com este repositório.
- Este repositório não é um canal público de distribuição nem indica homologação institucional.

## Preparação para versionamento

Antes do primeiro commit de código, revisar os arquivos para remover ou parametrizar URLs de rede internas, credenciais, dados pessoais, documentos administrativos, registros de execução e material de outros projetos. Preservar testes sintéticos, histórico técnico e arquivos indispensáveis ao funcionamento da extensão. Uma alteração no `manifest.json` deve preservar a compatibilidade com o ambiente de execução autorizado.

## Pesquisa e reprodutibilidade

A disponibilização futura de um pacote científico independente poderá envolver dados sintéticos, scripts de teste e uma versão demonstrativa sem acesso a serviços institucionais. Não publicar código ou dados do ambiente de trabalho sem verificação das autorizações aplicáveis.
